# OLX.kz Radar

[![CI](https://github.com/mengold774-glitch/olx_kz_radar/actions/workflows/ci.yml/badge.svg)](https://github.com/mengold774-glitch/olx_kz_radar/actions/workflows/ci.yml)

Персональный Telegram-бот для мониторинга объявлений на [OLX.kz](https://www.olx.kz).
Он регулярно проверяет публичную выдачу OLX по заданным фильтрам и сообщает о
подходящих объявлениях в Telegram.

Telegram bot for monitoring OLX.kz listings with customizable filters, SQLite
storage and real-time notifications.

Проект создан для личного использования и небольшого круга знакомых: чтобы не
пропустить квартиру, телефон, видеокарту, автомобиль или другой товар по
подходящей цене.

## Что умеет бот

- искать объявления по названию;
- выбирать категорию OLX.kz;
- ограничивать поиск городом;
- задавать минимальную и максимальную цену в тенге;
- выбирать новые или бывшие в употреблении товары;
- фильтровать частных продавцов и бизнес;
- использовать стоп-слова в заголовке;
- работать в быстром или полном режиме;
- уведомлять о новых объявлениях;
- отдельно отслеживать объявления, которые были повторно подняты продавцом;
- сохранять историю объявлений и изменения цены;
- экспортировать результаты в CSV или JSON;
- управлять всеми запросами через Telegram без веб-интерфейса.

## Как это работает

Бот не парсит HTML-страницы. Для поиска используется внутренний JSON API OLX.
Ответ API преобразуется в типизированную модель объявления, после чего бот
дополнительно проверяет цену, город, категорию, состояние и тип продавца на своей
стороне.

Это важно, потому что серверная выдача иногда может содержать объявления,
которые не полностью соответствуют фильтрам. Поэтому окончательное решение о
подходящем объявлении принимается локально.

Схема работы:

```text
Telegram
   │
   ▼
aiogram ──▶ SQLite
   │
   ▼
Монитор ──▶ OLX.kz API ──▶ фильтрация ──▶ уведомление в Telegram
```

Объявление становится доступным в выдаче OLX только после обработки самой
площадкой. Бот начинает отслеживание, когда оно появляется в публичном API, и
не может увидеть объявление раньше этого момента.

## Режимы мониторинга

### Быстрый режим

Проверяется первая страница выдачи с интервалом по умолчанию 25 секунд. Режим
подходит для популярных товаров, где важна скорость реакции.

### Полный режим

Бот периодически обходит несколько страниц выдачи. По умолчанию проверка
выполняется раз в 10 минут. Режим подходит для более полного сбора результатов,
но реагирует медленнее.

При определении новых объявлений бот сравнивает идентификаторы, а не положение
карточки на странице. Это предотвращает дубли из-за изменения порядка выдачи.

## Команды Telegram

| Команда | Назначение |
| --- | --- |
| `/start` | запустить бота и показать приветствие |
| `/add` | создать новый запрос мониторинга |
| `/list` | показать активные и приостановленные запросы |
| `/edit` | изменить цену, фильтры и режимы |
| `/del` | удалить запрос |
| `/export` | выгрузить найденные объявления |
| `/status` | показать состояние монитора |
| `/pause` | поставить мониторинг на паузу |
| `/resume` | возобновить мониторинг |
| `/cancel` | отменить текущий шаг мастера |
| `/help` | показать справку |

После `/start` бот показывает постоянное меню с кнопками для добавления,
просмотра, изменения и удаления запросов, управления паузой, статуса и экспорта.
Команды из таблицы остаются доступны, если удобнее вводить их вручную.

Чтобы добавить поиск, отправьте `/add` и последовательно выберите запрос,
ценовой диапазон, категорию, город, состояние, тип продавца и режим уведомлений.

## Доступ пользователей

Бот общедоступен: любой пользователь Telegram может открыть его и создать
собственные запросы. Запросы изолированы по Telegram ID — пользователь видит,
изменяет, удаляет и экспортирует только свои запросы, а уведомления приходят в
его чат.

В `.env`:

```dotenv
TELEGRAM_OWNER_ID=ваш_числовой_id
TELEGRAM_ALLOWED_IDS=
```

`TELEGRAM_OWNER_ID` остаётся обязательным: это чат для системных алертов
монитора (ошибки OLX, сети и базы). `TELEGRAM_ALLOWED_IDS` сохранён для
совместимости старых `.env`, но для доступа больше не используется.

При обновлении существующей базы колонка владельца запросов добавляется
автоматически. Старые запросы принадлежат владельцу из `TELEGRAM_OWNER_ID`.

## Технологии

- Python 3.11+;
- `curl_cffi` — HTTP-транспорт с отпечатком Chrome;
- `aiogram` — Telegram Bot API;
- SQLite и стандартный `sqlite3`;
- `pydantic-settings` — конфигурация из `.env`;
- `loguru` — логирование;
- Docker и Docker Compose — запуск на VPS или домашнем сервере.

## Установка на Windows

Откройте терминал VS Code в папке проекта:

```powershell
cd "C:\path\to\olx_Kz_radar"
```

Создайте виртуальное окружение и установите зависимости:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
```

Создайте файл конфигурации:

```powershell
Copy-Item .env.example .env
```

Заполните `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_OWNER_ID=ваш_числовой_id
TELEGRAM_ALLOWED_IDS=
OLX_DOMAIN=olx.kz
DB_PATH=./data/olx.db
```

Запустите бота:

```powershell
python -m olx
```

Терминал должен оставаться открытым. Для остановки нажмите `Ctrl+C`.

## Запуск через Docker Compose

Создайте `.env`, заполните токен и ID, затем выполните:

```powershell
docker compose up -d --build
```

Посмотреть логи:

```powershell
docker compose logs -f
```

Остановить контейнер:

```powershell
docker compose down
```

База SQLite и экспорт сохраняются в каталогах `data/db` и `data/exports`.

## Обновление справочников

Справочники категорий и городов находятся в `data/reference`.

Категории можно обновить из главной страницы OLX.kz:

```powershell
$env:TELEGRAM_BOT_TOKEN = "placeholder"
$env:TELEGRAM_OWNER_ID = "1"
python scripts\refresh_categories.py
```

Города собираются из нескольких широких запросов:

```powershell
python scripts\refresh_cities.py
```

Обновляйте справочники только при необходимости: скрипт городов выполняет
несколько сетевых запросов к OLX.

## Важные ограничения

- API OLX является внутренним и может измениться без предупреждения;
- проект рассчитан на небольшой личный объём запросов, а не на массовый сбор
  объявлений;
- бот отслеживает только объявления, доступные в публичной выдаче OLX.kz;
- задержка появления объявления зависит от модерации и обновления самой
  площадки;
- не храните токен Telegram в Git и не публикуйте `.env`;
- соблюдайте правила OLX и не используйте проект для передачи данных третьим
  лицам или массовой перепубликации объявлений.

## Безопасность

Файл `.env` содержит токен Telegram-бота и никогда не должен попадать в GitHub.
Если токен был опубликован или отправлен другому человеку, немедленно отзовите
его через `@BotFather` командой `/revoke` и создайте новый.
